# Bundled quick-start model

`SmolLM2-135M-Instruct.Q4_0.gguf` is a small, English-focused instruct model
included so a fresh clone can start the server immediately after installing
the `llama.cpp` runtime. It has 135 million parameters and is about 92 MB on
disk. Use it to try the interface and API; choose a larger model for useful
coding help, stronger reasoning, or reliable answers.
